# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Report a bug or suggest an enhancement

Open an issue describing the problem or idea. For bugs, include the inputs, expected result, actual result, and your operating system.

## Submit a change

1. Fork this repository and clone your fork.
2. Create a branch with a descriptive name.
3. Make a focused change and check the calculator with representative inputs.
4. Confirm Bash syntax with `bash -n simple-interest.sh`.
5. Commit your changes with a meaningful message and push the branch to your fork.
6. Open a pull request describing your change and how you checked it.

For example, a principal of 1000, annual rate of 5%, and period of 2 years should produce interest of 100.00. Check decimal inputs, zero values, and invalid input when changing the calculator.

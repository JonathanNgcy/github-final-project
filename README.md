# Simple Interest Calculator

A Bash calculator that computes simple interest from a principal amount, an annual interest rate, and a time period in years. Created for the IBM Introduction to Git and GitHub final project.

## Formula

```text
simple interest = principal × annual rate (%) × time (years) / 100
```

The rate is entered as a percentage: enter `5` for 5% per year.

## Requirements

Bash and awk, available on most Linux and macOS systems.

## Usage

```bash
bash simple-interest.sh
```

Enter the principal, annual rate, and number of years when prompted. All inputs must be non-negative numbers; decimals are supported.

## Example

```text
Enter the principal amount:
1000
Enter the annual rate of interest (%):
5
Enter the time period in years:
2
The simple interest is: 100.00
```

This educational calculator uses simple interest, without compounding.
